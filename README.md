# Эмулятор командной строки UNIX-подобной ОС

Консольный эмулятор оболочки UNIX с изолированной VFS в оперативной памяти (Вариант №25).

## 1. Общее описание

Эмулятор моделирует интерактивный диалог в терминале (REPL) либо исполняет пакетные команды из стартового скрипта:
- **Изоляция VFS**: данные модифицируются исключительно в ОЗУ в виде словаря байт `InMemoryVFS`.
- **Поддержка кавычек**: парсер на базе `shlex` обрабатывает пути и аргументы с пробелами.
- **Приглашение**: по умолчанию формируется на основе данных ОС (`username@hostname:~$ `).

## 2. Описание всех функций и настроек

### Параметры CLI
- `--vfs <путь>`: путь к ZIP-архиву виртуальной файловой системы.
- `--prompt <строка>`: пользовательское приглашение ввода.
- `--script <путь>`: путь к файлу сценария пакетного исполнения.

### Поддерживаемые команды
- `vfs-info`: имя VFS и SHA-256 хеш.
- `ls [путь]`: просмотр содержимого директории.
- `cd [путь]`: смена рабочего каталога (поддерживаются `.`, `..`, абсолютные пути).
- `head [-n N] <файл>`: вывод первых N строк файла.
- `du [путь]`: подсчет дискового пространства в КБ.
- `uptime`: время работы текущей сессии.
- `mv <источник> <назначение>`: перемещение/переименование узла в ОЗУ.
- `exit`: завершение работы.

## 3. Описание команд для сборки проекта и запуска тестов

Проект не требует сторонних зависимостей.

Запуск полного цикла тестов и сценария:
```bash
chmod +x run.sh
./run.sh
```

Ручной запуск модульных тестов:
```bash
python3 tests/generate_vfs.py
python3 -m unittest discover -s tests -v
```

## 4. Примеры использования

Интерактивный режим:
```bash
python3 src/main.py --vfs tests/vfs_deep.zip --prompt "my-shell$ "
```

Пакетный запуск:
```bash
python3 src/main.py --vfs tests/vfs_deep.zip --script tests/startup.txt
```
